# MotionBench RFCs

Substantial changes — new tasks, changes to the trace format, scoring rules,
weights, governance — go through a public Request for Comments.

1. Copy `0000-template.md` to `NNNN-short-title.md` (next free number).
2. Open a pull request and a thread in GitHub Discussions, category "RFCs".
3. Comment period: at least 14 days (21 for spec changes).
4. Decision by lazy consensus of committers; any committer may call a vote
   (+1 / 0 / −1, at least three binding +1 and more +1 than −1).
5. Accepted RFCs are merged and frozen; changes need a superseding RFC.
